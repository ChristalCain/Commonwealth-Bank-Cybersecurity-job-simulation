# Task 2 – Incident Response

## Overview
Analyzed a fictional cybersecurity incident involving a phishing attack and developed appropriate incident response and recovery actions.

## Work Completed
- Identified the attack as phishing based on the provided incident details.
- Determined appropriate steps for detecting, confirming, prioritizing, and reporting the incident.
- Developed containment and recovery actions, including preserving evidence, isolating affected systems, removing malicious components, and restoring normal operations.
- Identified post-incident activities, including documenting the incident, conducting a lessons-learned review, strengthening security controls, and improving future response processes.

- Incident Response
- Phishing Analysis
- Incident Containment
- Evidence Preservation
- Eradication and Recovery
- Post-Incident Analysis
