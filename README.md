# Commonwealth Bank Introduction to Cybersecurity Job Simulation

This repository documents my completion of the Commonwealth Bank Introduction to Cybersecurity Job Simulation through Forage.

The simulation provided hands-on experience in cybersecurity data analysis, incident response, security awareness, and web application penetration testing.

## Task 1 – Data Analysis

Used Splunk Enterprise to analyze a provided fraud-related dataset and develop a dashboard to identify and visualize patterns in the data.

**Skills & Tools:** Splunk Enterprise, Data Analysis, Data Visualization, Dashboard Development

[View Task 1](Task-1-Data-Analysis)

## Task 2 – Incident Response

Analyzed a fictional phishing incident and developed appropriate incident response actions, including containment, evidence preservation, eradication, recovery, and post-incident review.

**Skills:** Incident Response, Phishing Analysis, Incident Containment, Evidence Preservation, Recovery

[View Task 2](Task-2-Incident-Response)

## Task 3 – Security Awareness

Created an employee-facing password security awareness infographic based on Australian Cyber Security Centre (ACSC) guidance on strong passwords and passphrases.

**Skills & Tools:** Security Awareness, Password Security, Security Communication, Canva

[View Task 3](Task-3-Security-Awareness)

## Task 4 – Penetration Testing

Completed 11 beginner-level web application security labs in the authorized PortSwigger Web Security Academy environment and documented the findings in a structured penetration testing report.

The labs covered SQL injection, cross-site scripting (XSS), authentication flaws, access control vulnerabilities, path traversal, and OS command injection.

**Skills & Tools:** Burp Suite, PortSwigger Web Security Academy, Web Application Security, Penetration Testing, Vulnerability Analysis, Technical Reporting

[View Task 4](Task-4-Penetration-Testing)

All penetration testing activities documented in this repository were performed in intentionally vulnerable, authorized educational lab environments as part of the Commonwealth Bank Forage job simulation and PortSwigger Web Security Academy. No unauthorized systems were tested.
