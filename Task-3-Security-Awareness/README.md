# Task 3 – Security Awareness

## Overview
Created a security awareness resource focused on password and passphrase security for employees.

## Work Completed
- Researched Australian Cyber Security Centre (ACSC) guidance for creating strong passwords and passphrases.
- Designed an employee-facing security awareness infographic communicating password security best practices.
- Highlighted the importance of using long, unpredictable, and unique passphrases.
- Included guidance on password managers and multi-factor authentication (MFA) to improve account security.

## Tools & Skills
- Security Awareness
- Password Security
- Security Communication
- Security Best Practices
- Canva

## Deliverable
Created a Password Security Awareness infographic designed to communicate password security recommendations in a clear and accessible format.
